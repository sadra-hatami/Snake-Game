# 📖 About

**Snake Game** is a fullscreen arcade game built with Python and Pygame.

The board is a green checkerboard. The snake starts in the center. Food is red. After each bite the score rises and more food appears on the board. Wall hits and self-hits end the round, then the game returns to a fresh snake and keeps the high score.

Controls work from the arrow keys or from four on-screen buttons, so the same build can be played on a desktop or a touch screen.

> **Tagline:** *A fullscreen Pygame snake game with on-screen controls, a rising food count, and a high score.*

---

# 🚀 Why This Game?

A snake demo is usually a tiny window and one apple.

This version is built as a short session you can actually play:

- The window opens fullscreen
- A start screen sits in front of the first round
- Direction buttons stay on the board
- Food multiplies as the score climbs
- The high score survives the next game over

It is a self-contained Pygame piece, separate from the browser snake inside [Arcade Games Website](https://github.com/sadra-hatami/Arcade-Games-Website).

# ✨ Key Features

- 🖥️ Fullscreen play
- 🎬 Start screen before the first round

- 🏆 Score and high score

- 🔁 Automatic restart after game over

# 🎮 How to Play

1. Run the game.
2. Press **Start**.
3. Steer with the arrow keys or the on-screen pad.
4. Eat the red squares.
5. Avoid the border and your own body.

Each bite adds one point and brings more food onto the board. After a crash, the high score stays and a new round begins.

# ❓ Frequently Asked Questions

### Does it need a server?

No. It is a local Pygame window.

### Why fullscreen?

The board and the direction pad are sized from the current display.

### Is this the snake inside Arcade Games Website?

No. That one runs in the browser. This repository is a standalone Pygame game.

### Does the high score stay after closing the game?

It stays for the current run. Closing the program clears it.
